# Evaluation Plan

Record the following results before describing the project as effective.

## Detection

- Label each simulated run and fault onset.
- Calculate precision, recall, and false alarms for the detector.
- Measure detection delay from injected fault onset.
- Test normal operation across multiple random seeds.

## Copilot grounding

- Prepare questions with expected supporting manual sections.
- Check whether responses cite relevant retrieved text.
- Track unsupported claims and unanswered questions.
- Ensure the response distinguishes a hypothesis from a confirmed cause.

## Product quality

- Measure response latency and, when using an LLM, cost per query.
- Test missing data and unknown scenarios.
- Confirm that every physical intervention is framed as requiring authorized human review.

Do not report simulated improvements as real factory downtime or financial savings.
